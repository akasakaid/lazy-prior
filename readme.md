## Requirements
* Python 3.10+  
* Git  

## Installation
```bash
# Clone repository
git clone https://github.com/akasakaid/lazy-prior.git

# Navigate to folder
cd lazy-prior

# Create Python virtual environment (optional)
python3 -m venv env

# Activate virtual environment (if created)
# Windows:
env\scripts\activate
# Linux/Mac:
source env/bin/activate

# Install required libraries
pip install -r requirements.txt

# Run swap.py
python swap.py
```

## Configuration
Add your wallet private keys (for testnet tasks) to privatekeys.txt. Each line should contain only 1 private key.

Example privatekeys.txt content:
```
0xprivatekey1
0xprivatekey2
0xprivatekey3
```
